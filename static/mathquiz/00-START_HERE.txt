================================================================================
   DÉMARRAGE RAPIDE (4 ÉTAPES)
================================================================================

1. INSTALLER LES DÉPENDANCES
   Ouvrez R ou RStudio et exécutez :

   setwd("C:/Users/hp/Documents/GitHub/aladasic.github.io/static/mathquiz")
   source("install_dependencies.R")

2. CONFIGURER LES CHEMINS (IMPORTANT!)
   Configurez automatiquement le chemin vers votre repository maths :

   source("setup_paths.R")

3. CONSTRUIRE LA BANQUE DE QUESTIONS
   Générez 80 questions depuis vos fichiers LaTeX :

   source("build_question_bank.R")

4. LANCER L'APPLICATION
   Démarrez l'application Shiny :

   shiny::runApp("app.R")

   OU dans RStudio : Ouvrez app.R et cliquez sur "Run App"

================================================================================

✅ PARSING AUTOMATIQUE
   - Extraction des définitions, propositions et remarques depuis LaTeX
   - Nettoyage intelligent du code LaTeX
   - Préservation de la notation mathématique

✅ GÉNÉRATION DE QUESTIONS
   - 20 questions par chapitre (80 au total)

================================================================================
   DÉPANNAGE
================================================================================

PROBLÈME : "Questions file not found"
SOLUTION : Exécutez source("build_question_bank.R")

PROBLÈME : Parser retourne 0 items
SOLUTION : Vérifiez que vos fichiers LaTeX utilisent les environnements
           \begin{definition}[...], \begin{proposition}[...], etc.

PROBLÈME : "Cannot find maths repository"
SOLUTION : Modifiez maths_repo_path dans config.yaml

PROBLÈME : Les packages ne s'installent pas
SOLUTION : Installez manuellement :
           install.packages(c("shiny", "bslib", "shinyjs", "yaml",
                             "stringr", "stringdist"))

POUR PLUS D'AIDE : Exécutez source("test_setup.R")
