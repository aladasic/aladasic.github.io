🚀 Quick Start

⚠️ Important: You need R and RStudio installed to run this application.
1
Install Dependencies
Open R or RStudio and run:
source("install_dependencies.R")
2
Build Question Bank
Generate 80 questions from your course files:
source("build_question_bank.R")
3
Launch the App
Start the Shiny application:
shiny::runApp("app.R")
